# Runscars web

Aplicación definitiva de Runscars. Conserva la dirección visual validada en la
fase 2 y usa Next.js estándar para el despliegue en Vercel.

Los comandos se ejecutan desde la raíz del repositorio:

```bash
npm ci
npm run dev
npm run verify
npm run test:e2e
```

La configuración completa de aplicación, Supabase, fixtures y staging está en
[`../docs/TECHNICAL_FOUNDATION.md`](../docs/TECHNICAL_FOUNDATION.md).
